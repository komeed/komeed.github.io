# Omeed Kasnavi's GitHub Pages Site

Personal portfolio and repository portal for [Omeed Kasnavi](https://github.com/komeed).

🌐 **Live Site:** [https://komeed.github.io](https://komeed.github.io)

## Features
- **All Repositories Tab**: Live dynamic synchronization and embedded listing of all public repositories with language tags, star counters, and direct links.
- **Quick Repositories Floating Tab**: Floating quick drawer allowing instant 1-click access to any repository from anywhere on the page.
- **Search & Filters**: Real-time filtering by search query and language tag (C, C++, Swift, Java, C#, etc.).
- **Featured Projects**: Curated showcase of projects including embedded simulators, game modding (Silksong PVP with 1.2k+ downloads), and AI/systems projects.
- **Responsive & Modern Design**: Clean dark theme with smooth animations, mobile friendliness, and accessible layout.

## Local Development
Simply open `index.html` in your browser or run a lightweight HTTP server:
```bash
python3 -m http.server 8000
```
Then navigate to `http://localhost:8000`.
